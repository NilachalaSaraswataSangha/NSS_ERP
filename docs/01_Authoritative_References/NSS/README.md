# docs/01_Authoritative_References/NSS/

Source-faithful transcription of NSS's Constitution & Bye-Laws, organized by legal section.
REF documents preserve original authoritative wording — no paraphrasing or ERP interpretation
injected (see `docs/00_Project_Governance/AUTH/AUTH-001_Authoritative_Reference_Standard.md`).
REF identifiers belong to the document, not the folder.

Transcribed from `BY-LAW/NSS/NSS BYE-LAW.pdf` (cross-checked against `BY-LAW/NSS/NSS_Bye_Law.docx`)
at the repository root — every REF document below also cites this under its own "Source
Information" → **Source File(s) in Repository** field.

NSS ERP — Unified STATUS Badge Preview

All 16 lifecycle statuses from master_data category STATUS (database/seed/01_foundation/02_master_data.sql), shared across all ERP modules (Organization, Membership, Governance, etc.) — each module sees only its applicable subset via master_data.applicable_modules. The separate credential, account and claim status domains follow below.

This page is the visual source of truth. Its geometry and palette are mirrored verbatim in frontend/assets/css/badges.css, so the two can be diffed by eye. Change both together — never add a page-local badge override.

Fill convention: a SOLID fill with white text means a state the record actually holds. An OUTLINE badge (.badge-muted) is metadata — record counts, "not implemented" placeholders, data-type hints — so real statuses stay visually dominant.

User Account Statuses — badge-account-*

The complete set allowed by chk_user_account_status in database/ddl/06_authentication/01_user_account.sql. A separate domain from the lifecycle STATUS category, so it gets its own class prefix rather than borrowing badge-status-* by coincidence. Note SUSPENDED and DEACTIVATED are not valid account statuses.

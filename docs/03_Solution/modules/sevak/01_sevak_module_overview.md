# NSS ERP Sevak Sangha Module Overview

Version: 1.0
Status: PARTIALLY FROZEN

---

# 1. Purpose

The Sevak Sangha Module manages participation, training, orientation, volunteer development, leadership development, service activities, and development of future NSS workers and leaders.

Sevak Sangha is an NSS operational institution focused on training, service and character development.

---

# 2. Core Definition

Sevak Sangha is: Training Organization, Volunteer Organization, Service Organization, Leadership Development Platform.

It is NOT: NSS Membership Category, Governance Body, Election Body.

---

# 3. Relationship With NSS Membership

Additional organizational/operational layer. Does not create separate Membership Type.
Sangha Sevi ID remains authoritative identity.

---

# 4. Historical Development

1973: First Sevak Sangha — Naukona Sangha, Kendrapara District, 18 Members.
1987: Ekamra Sevak Sangha — Satsikshya Mandir, Bhubaneswar.
1991: Kendra Sevak Sangha established (Ekamra merged into Kendra).

---

# 5. Core Activities (Frozen)

Orientation Classes, Sadachara Training, Seva Training, UPBS Volunteer Training, Bhakta Sammilani Support, Social Service Activities, Character Development.

---

# 6. Eligibility (Working Frozen)

Youth, Teenagers, Students, Sevaks, Interested NSS Members.
Exact age criteria NOT yet frozen.

# 7. Governance

# NSS ERP Mahila Sangha Lifecycle

Document ID: SOL-MAH-003
Status: DRAFT

---

# 1. Person to Mahila

Person -> NSS Membership -> Sangha Sevi ID -> Mahila Sangha Participation

---

# 2. Membership Lifecycle

Shared with common NSS Membership: PROBATIONARY, REGULAR, ASSOCIATE.
No separate Mahila lifecycle.

---

# 3. Participation

Sangha Sevi -> Mahila Participation -> Mahila Sakha Sangha

---

# 4. Activities

Mahila Participant -> Mahila Activity -> Participation History

---

# 5. Governance

Eligible Member -> Body Assignment -> Mahila Parichalana Mandali -> Position
Historical assignments preserved.

---

# 6. Renewal and Transfer

No separate Mahila renewal. No separate Mahila transfer.
Common NSS processes apply.

---

# 7. Lifecycle Principles

- Mahila Participation Does Not Create New Membership
- Sangha Sevi ID Remains Permanent
- Membership Lifecycle Is Shared
- Governance Assignments Are Historical
- Activities Are Historically Recorded
- History Never Deleted

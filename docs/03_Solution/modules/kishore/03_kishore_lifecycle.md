# NSS ERP Kishore Puja Lifecycle

Document ID: SOL-KIS-003
Status: DRAFT

---

# 1. Person to Kishore

Person -> Kishore Registration -> KH000123 -> Guardian Assigned -> Active

---

# 2. Annual Event Registration

Each year: KH000123 registers for that year's Kishore Puja event.
Same ID across years. No new ID per year.

---

# 3. Guardian Assignment

Before registration is complete, Guardian must be assigned.
Guardian: NSS Member of participant's Sakha, assigned by Sakha.

---

# 4. Multiple-Year Participation

KH000123: 2026, 2027, 2028 — same ID, separate registrations.

---

# 5. Registration Sources

Parent Nomination: Parent -> Nominate Son -> Registration -> Sakha -> Guardian
Sakha Nomination: Sakha -> Nominate Boy -> Registration -> Guardian

---

# 6. Sakha Change

2026 -> Ekamra Sakha
2028 -> Rourkela Sakha
Each registration preserves its own Sakha.

---

# 7. Membership Transition

KH000123 -> Application -> Assessment -> Approval -> SS000456
Kishore ID remains. Both identities linked via kishore_membership_transition.

---

# 8. No Automatic Membership

Participation does not automatically create NSS Membership.

---

# 9. Lifecycle Principles

- Kishore ID Is Permanent
- Annual Events Have Separate Registrations
- Sakha Association Preserved Per Registration
- Guardian Assignment Required
- Guardian Is NSS Member of Participant's Sakha
- Membership Transition Is Explicit
- History Never Deleted

# NSS ERP Kumari Sangha Lifecycle

Document ID: SOL-KUM-003
Status: DRAFT

---

# 1. Person to Kumari

Person -> Kumari Enrollment -> KM000123 -> ACTIVE

---

# 2. Active Participation

During active participation: Activities, Dina-Lipi, Niyam Panchak, Dasa Sheela, Training.

---

# 3. Marriage Exit

ACTIVE -> Marriage -> MARRIED_OUT
Participant record retained.

---

# 4. Withdrawal

ACTIVE -> WITHDRAWN
Historical participation preserved.

---

# 5. NSS Membership Transition

KM000123 -> Application -> Assessment -> Approval -> SS000456
Kumari ID remains unchanged. Both identities linked.

---

# 6. Membership Type Decision

Long-term participant may be considered for REGULAR or PROBATIONARY.

---

# 7. Assessment Inputs

Years of participation, Dina-Lipi, Niyam Panchak, Dasa Sheela, Training, Conduct, Discipline, Seva participation, Leadership recommendation.
These are inputs and do not themselves grant Membership.

---

# 8. Kumari Status After Membership

Status becomes: BECAME_NSS_MEMBER
Kumari history remains available.

---

# 9. End States

MARRIED_OUT, BECAME_NSS_MEMBER, WITHDRAWN, DECEASED

---

# 10. Frozen Principles

- Kumari Participation is not NSS Membership
- Kumari ID Is Separate from Sangha Sevi ID
- Sangha Sevi ID Generated Only After Membership Approval
- Kumari History Never Deleted
- Marriage Is Explicit Exit Condition
- Membership Transition Is Explicit
- Historical Identity Link Is Permanent

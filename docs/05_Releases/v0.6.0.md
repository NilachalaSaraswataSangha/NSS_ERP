# Overview

This is the largest release in NSS ERP history. It takes the project from a Person-schema-only
state (v0.5.1) to a fully operational Tier 0 vertical slice: 22-module design documentation,
18-table database implementation, a FastAPI bootstrap API, a responsive Bootstrap Verification
UI, and live deployment on Render.com + Neon.dev.

Every module in the NSS ERP roadmap now has complete (or near-complete) solution-layer design
documentation. Three database vertical slices are implemented in SQL. The first web UI is live
and verifiable.

## 3. Database Vertical Slices (18 Tables Implemented)

### Bootstrap RBAC (3 tables)

Under `database/ddl/00_bootstrap/` and `database/seed/00_bootstrap/`:

* `role_master` — 8 frozen roles (3 SYSTEM with NSS-WIDE scope, 5 ORGANIZATIONAL)
* `permission_master` — structure ready, catalogue populated progressively
* `role_permission` — structure ready, mappings populated progressively

Key change in this release: SYSTEM roles (`NSS_ERP_ADMIN`, `NSS_ERP_AUDITOR`,
`NSS_ERP_REPORT_VIEWER`) now carry `scope_level = 'NSS-WIDE'` instead of NULL.
The `chk_role_master_scope_level` CHECK constraint includes `NSS-WIDE` in its allowed values.

### Foundation (12 tables)

Under `database/ddl/01_foundation/` and `database/seed/01_foundation/`:

* `master_category`, `master_data` — generic master-data-driven pattern
* `system_setting` — application configuration
* `id_sequence_master` — centralized ID generation
* `country`, `state`, `district`, `city_village` — geographic hierarchy
* `postal_code`, `city_village_postal_code` — postal code mapping
* `document_master` — cross-module document storage
* `field_change_log` — field-level change audit

All 12 tables seeded with reference data. Soft-delete CHECK constraints on all
`is_active` tables. `deleted_at` backfill applied.

### Organization (3 tables)

Under `database/ddl/02_organization/` and `database/seed/02_organization/`:

* `organization_type_master` — 8 frozen org types
* `organization_status_master` — status reference
* `organization` — self-referencing hierarchy via `parent_organization_pk`

All tables use `nss.` schema prefix. PostgreSQL infrastructure roles: `nss_db_owner`,
`nss_db_backend`.

## 4. FastAPI Tier 0 Bootstrap API

Under `api/`:

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/v1/bootstrap/health` | GET | Database connectivity check |
| `/api/v1/bootstrap/roles` | GET | List all 8 RBAC roles |
| `/api/v1/bootstrap/permissions` | GET | List permissions (empty in Tier 0) |
| `/api/v1/bootstrap/roles/{role_pk}/permissions` | GET | Permissions for a specific role |

* Raw `psycopg2` — no ORM
* No authentication (by design for Tier 0)
* Connects as `nss_db_backend` role
* Pydantic response schemas (`RoleResponse`, `PermissionResponse`)

## 5. Tier 0 Bootstrap Verification UI

Under `frontend/`:

* **Tech stack:** Tailwind CSS + DaisyUI (CDN) + Alpine.js (CDN)
* **No build step** — served as static files by FastAPI
* **Responsive 3-column layout:**
  - Mobile (< 768px): 1 column stacked
  - Tablet (768px-1279px): 2 columns
  - Desktop (>= 1280px): 3 columns side by side
* **Dynamic viewport width** — progressive padding (`px-6`, `lg:px-10`, `2xl:px-16`), no max-width cap
* **Sections:** System Status, RBAC Roles (clickable), Permissions, Role Permissions (drill-down)
* **Table features:** `table-sm` density, hover tooltips, Active column (checkmark/cross), badge indicators for role class and module
* **Interactive:** Click a role to see its permissions; toggle deselect on same role

# Notes

This release represents the transition from design-only to a working vertical slice. The
entire 22-module design layer is now in place, providing a complete blueprint for the
remaining implementation tiers. The Tier 0 Bootstrap Verification UI proves the
database-to-API-to-UI pipeline end to end.

The v0.5.1 Person DDL (`database/ddl/03_person/`) is documented as a superseded prototype
(uses per-domain master tables instead of the generic `master_category`/`master_data` pattern)
and will be rewritten in a future release.

# Overview

This release completes the foundational database schema for the NSS ERP Person Module.

The release introduces the complete Person data model, supporting international contact information, multiple addresses, location hierarchy integration, auditability, and future Membership integration.

# Frozen Business Decisions

## Person

* Person ≠ Member
* Membership depends on Person
* Date of Birth optional for Person
* Date of Birth mandatory before Membership approval
* Mobile Number + Country Phone Code unique
* Email not unique
* At least one contact method required

---

## Address

* Multiple addresses allowed
* One Primary Address allowed
* Primary Address may be changed
* Location mapping enforced through city_village_postal_code_map

Supported:
